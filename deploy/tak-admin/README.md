# 香港 TAK 管理台与到港航班

管理界面在 OpenTAKServer 原生页面上新增值班和部署导航。页面链接继续打开原生路由，服务端权限、证书、插件和地图包 API 由 OpenTAKServer 管理。Ops 内嵌地图独立运行，不加载管理导航。

将本目录下的 Nginx 配置及 JS、CSS 放在 `/opt/golf-tak-admin`。在原生 HTTPS Web 管理的 server 块加入 `include /opt/golf-tak-admin/original-site.conf;`。既有私有地图入口采用 [tak-map.conf](../ops-live/tak-map.conf)。用 `nginx -t` 验证后重新加载配置。

桌面试点管理入口是 `http://127.0.0.1:18081/dashboard`。航班表在 `http://127.0.0.1:18080/?view=flights`，需要试点访问码。

Ops 的航空数据来自香港机场官网当日客运到港接口。响应显示数据源更新时间，单进程共享缓存九十秒。读取失败时保留上次成功的数据并标明状态；过了香港当地午夜后会切到新日期。预计、已落地、已到达机位和取消单独展示。用于私有试点，机场网页接口变动或不可用时，可以在航班页打开官方到港看板。

原生地图及 Ops 内嵌地图通过本目录的 `aircraft.js` 和 `aircraft.css` 显示香港航空图层。图层从登录后的 TAK CoT API 读取本机 ADSBCOT 发布的航空事件，标注呼号和位置时间。源点位过期后会变灰，并最多保留至采集后六分钟。飞机点位的采集仍按服务端五分钟周期运行。图层按钮可隐藏航迹或缩放到香港空域。

到港列表使用同一条记录的首个公布航班及其 ICAO 航司代码推导候选呼号。代码共享航班号仍展示为该记录的别名。地图要求呼号和到港记录都唯一，且点位时间落在该记录的到港时间窗口内。地图弹窗使用香港机场的预计、落地或到达机位状态。机场数据过时或无可靠关联时保留原始航迹显示。原生地图通过 TAK 会话认证读取同一个 Ops 机场缓存。

香港气象层默认显示赤鱲角站的十分钟平均风和能见度，可切换为分区风况、分区能见度或过去一小时实测雨量。观测值来自香港天文台，站点位置来自 CSDI。风况和能见度通过同源的只读 Nginx 路由读取；上游不接收浏览器请求头或凭据。雨量模式点击站点可查看观测时间并打开香港天文台天气雷达。

香港试点调度员可在到港表选择「关联接机」。关系以香港机场服务日期和主航班号标识，并归属创建关联的调度员。当日观测每 15 秒检查一次，和航班表共用 90 秒的机场数据缓存。机场新观测产生延误、落地或到达机位提醒，重复观测合并为同一条提醒。工作台每 4 秒读取状态。点击提醒读取任务当前的司机和车辆；接单、会合和交接仍走原有任务动作。
